VOIS AICTE Project – October 2025
📌 Overview

This project was developed as part of the VOIS–AICTE Internship Program (Oct 2025).
It focuses on analyzing Airbnb open data to uncover insights, trends, and patterns using data analytics and machine learning techniques.

The project includes:

Exploratory Data Analysis (EDA) on Airbnb dataset

Data preprocessing & visualization

Predictive insights for pricing and demand

Notebook implementation in Python

🚀 How to Run

Clone this repository:

git clone https://github.com/2300033094/VOIS_AICTE_Oct2025_ChaithanyaKumar.git

cd VOIS_AICTE_Oct2025_ChaithanyaKumar


Install required dependencies:

pip install -r requirements.txt


(create requirements.txt with necessary libraries if not already present)

Open Jupyter Notebook:

jupyter notebook VOIS_AICTE_Oct2025_ChaithanyaKumar.ipynb

📊 Dataset

Source: Airbnb Open Data (Excel file provided: Airbnb_Open_Data.xlsx)

Features include: location, room type, price, availability, host details, etc.

Dataset is used for analyzing trends, pricing patterns, and neighborhood insights.

✨ Results & Insights

Visualizations highlight price distribution, location-based trends, and seasonal availability.

Helps understand factors affecting Airbnb pricing & demand.

Forms a base for predictive modeling in real-world rental markets.
